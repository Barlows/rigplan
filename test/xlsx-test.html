XLSX writer

Writing a real .xlsx with nothing installed. An xlsx is a ZIP archive of XML parts, and ZIP's "stored" method is a valid compression method, so a conforming archive can carry uncompressed members. What has to be exactly right is the structure: every reader uses the central directory, so an archive whose local headers are fine but whose central directory is wrong looks plausible and will not open at all. These tests walk the archive the way a reader does, with an implementation written from the ZIP spec rather than from the writer's own helpers.
