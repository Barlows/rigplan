How this works

Place parts, then click one terminal and another to run a cable. Set the run length in the inspector; every cable is sized for ampacity and voltage drop against the selected standard.

Keyboard
  • V select · W cable
  • F fit · wheel to zoom · space-drag to pan
  • ⌘Z undo · ⇧⌘Z redo
  • ⌘D duplicate · ⌫ delete

Sizing method

Design current includes the standard's continuous-load factor. Cable ampacity comes from the published table, derated for ambient temperature, grouping and installation method. The smallest cable that passes both ampacity and voltage drop wins.

Every suggestion is a starting point for a qualified person to check — not a certification.
